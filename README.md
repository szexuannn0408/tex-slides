# tex-slides
DVN - Practice

This repository hosts the RITS consultation slide deck, compiled for 36104 Data Visualisation and Narratives (Session 3, Part E).

The 77-slide deck was compiled locally from the supplied LaTeX source with XeLaTeX (MacTeX). Beamer lays out the slides and TikZ draws the diagrams. GitHub Pages publishes the PDF.
